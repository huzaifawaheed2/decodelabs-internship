# Data Cleaning & Preparation Project

## Project Overview
This project was completed as part of the DecodeLabs Data Analytics Internship (Project 1).

The objective of this project was to clean and prepare a raw dataset for analysis using Microsoft Excel Power Query.

## Tools Used
- Microsoft Excel
- Power Query
- Microsoft Word
- GitHub

## Dataset Information
- Total Records: 1200
- Total Columns: 14
- Unique Order IDs: 1200

## Data Cleaning Tasks Performed
1. Imported dataset into Power Query
2. Performed data profiling
3. Standardized date format
4. Validated unique Order IDs
5. Handled missing CouponCode values
6. Verified data types
7. Performed final validation
